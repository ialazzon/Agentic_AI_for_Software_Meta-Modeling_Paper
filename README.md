# Agentic AI for Ecore Model Generation and Validation

This repository contains the source code, experimental artifacts, and supporting material associated with the journal paper presenting an **Agentic AI for Meta-Modeling**.

## Repository Structure

### `Experiments/`

The `Experiments` directory contains the experimental artifacts for the **26 Ecore metamodels** used in the benchmark dataset. Each subdirectory corresponds to one metamodel and contains the metamodel definition, its graphical representation, the natural-language input description, OCL constraints, and the models generated by the proposed framework and the baseline LLMs (GPT and Claude).

For example, the `Accounting` directory contains:

```text
accounting.ecore
accounting.ecore.jpg
accounting_claude.model
accounting_gpt.model
constraints.txt
description.txt
generated_model.model
generated_model.model.jpg
```

Here, `generated_model.model` is the model produced by the proposed agentic framework, while `accounting_gpt.model` and `accounting_claude.model` are the corresponding models generated through direct prompting of GPT and Claude.

### `Family models/`

This directory contains **10 model instances of the Family metamodel** generated automatically using the extended framework. These artifacts demonstrate the capability of the framework to generate multiple model instances without requiring a human-written natural-language specification for each instance.

### `java/`

The `java` directory contains the Java source code used to implement the **OCL constraint validation engine**. In particular, `OCLValidator.java` provides the functionality required to evaluate OCL constraints against generated model instances.

### `Python source code/`

This directory contains the Python implementation of the proposed framework.

`agentic1.py` is the main program implementing the agentic workflow for generating and validating a model instance from a natural-language description and an Ecore metamodel.

`agentic2.py` extends the framework with support for automatically generating an arbitrary number of model instances from a source metamodel.

The remaining Python modules provide supporting functionality used by these workflows. Examples include:

- `check_conformance` — checks whether an XMI model conforms to its Ecore metamodel.
- `ecore_to_json` — converts an Ecore metamodel into a JSON representation.
- `xmi_converter` — converts an XMI model into YAML.
- `ocl_runner` — invokes the OCL validation engine on a generated model.
- `requirements.txt` — specifies the Python dependencies required to reproduce the development environment.

A compatible Python virtual environment can be created using:

```bash
python -m venv venv
```

followed by:

```bash
pip install -r requirements.txt
```

## Demonstration Video

The repository also includes a **video containing sample runs of the agentic framework**. The demonstration illustrates the execution workflow and the generation and validation of model instances from Ecore metamodels and natural-language specifications.

## Reproducibility

The repository is intended to support reproducibility of the experiments reported in the accompanying journal paper. It provides the benchmark metamodels, input descriptions, OCL constraints, generated models, baseline outputs, implementation source code, and demonstration material used in the evaluation.
